## 初测发现与修复

保留初测失败，不把重跑覆盖成首次成功。

1. 事件表占位符数量错误：第一轮组件测试发现并修复。
2. 模型输出遗漏必需字段：将完整 JSON Schema 加入提示词；语义证据校验也进入一次修复路径。
3. 冷启动口吻暗示不存在的前文或现场观察：强化已说内容与内部意图区分，虚构场景必须明确标记。
4. 浏览器测试容器默认 root 导致证据数据库权限错误：测试容器使用宿主 UID/GID。
5. DSH 每次重复传入初始化参数：独立 profile 只初始化一次，后续正常启动。
6. DSH 网页读取受 Fake-IP 解析影响：通过 DSH 支持的 HTTP_PROXY/HTTPS_PROXY 显式连接宿主代理。
7. 视觉初测将 Linux 桌面称作 Windows：传入可信采集平台元数据；后续重测正确识别 Linux X11。页面细字仍需按图复核，不能把模型文本当作图像事实真值。
8. 查询回复偶尔省略 URL：真实查询来源以独立链接随消息存储和显示。
9. 明确截图请求被模型重复确认：提示约束明确用户请求及开关已构成执行授权，暂停主动交流不禁用用户请求。
10. 第一次可见界面测试中途收到额外真实输入 `hello`，天气在途结果被上下文版本作废；该次天气显示样本按 INVALID 保留并重测。

原始证据仅在本机 `artifacts/`，包含截图、会话数据库、模型用量和提示词哈希；这些文件不上传公开仓库。公开摘要不包含密钥、个人桌面截图或本机账号信息。

## 使用边界

- 真实模型短样本与三小时虚拟时钟不代表长期无人值守稳定性。
- DSH 查询有独立 90 秒超时与每小时查询次数上限；底层 DSH 自身的模型 token 计量由其会话记录维护，不计入 Weave 五区模型调用统计。
- 日期与来源冲突按原样呈现，不用平均数或猜测消除冲突；故事为简短转述，不冒充原典逐字引文。
